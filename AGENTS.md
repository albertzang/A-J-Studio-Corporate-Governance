## Cursor Cloud specific instructions

### Verifying edits

This site is a static page (`index.html`, `assets/styles.css`, `assets/app.js`).

For wording, names, links, or other copy changes, verify by reading the file and fetching the local page, then checking that the expected strings are present. Do not take browser screenshots or screen recordings for those edits.

Open the page in a browser only when layout, styling, navigation, or another interaction changed.

### Desktop editing

The git checkout is `/workspace`. A symlink at `~/Desktop/A-J-Studio-Corporate-Governance` points at that same checkout, so edits there are the agent's working tree. Open it in VS Code with `code /workspace`, or from the Desktop shortcut. `code` is on `PATH`.

### Contents navigation

The contents list includes heading levels 1 and 2 only: the numbered sections, and their subsections numbered like 2.1. Deeper headings stay on the page and are not added to the contents list. Do not raise that depth unless asked.
